# Support

## Usage And Contribution Questions

1. Read [README.md](README.md) for the foundation overview.
2. Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening pull requests.
3. Use GitHub issues for reproducible bugs or well-scoped feature requests.

## Security Issues

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).

## Maintainer Expectations

1. Keep issues focused and reproducible.
2. Include validation steps, expected behavior, and observed behavior.
3. For contribution questions, include the branch name, commit message, and command output where relevant.
